二、检察院端（后端）功能详情
系统全程部署于检察内网，与互联网前端物理隔离，采用「左侧固定导航栏 + 右侧主操作区」的标准政务系统布局，符合检察官办案操作习惯
一、系统首页：办案总览大屏
核心办案数据、待办任务、风险预警一眼可达
1、顶部通栏固定区
左侧：系统主标题【欠薪支持起诉智能办案平台（检察端）】，下方标注所属检察院名称
右侧：依次显示登录检察官姓名、办案权限、待办任务红点提醒、系统公告、退出登录按钮
第一区块：核心办案指标看板（通栏 4 张并列数字卡片，醒目分级标注）
卡片 1：待研判线索总数（红色加粗数字），下方标注「今日新增 XX 条」；
卡片 2：待审查重点线索数（黄色加粗数字，特指前端勾选「需要支持起诉」的线索），下方标注「超期预警 XX 条」；
卡片 3：办理中支持起诉案件数，下方标注「本月新受理 XX 件」；
卡片 4：已办结案件数，下方标注「支持起诉采纳率 XX%」。
2、核心业务区
左侧（60% 宽度）：【我的待办任务清单】，按优先级倒序排列，每条任务显示：线索编号、诉求类型、涉事工地 / 企业、提交时间、任务类型（待研判 / 待审查 / 待取证 / 待文书审核），右侧对应【立即办理】【一键分流】操作按钮；清单下方为【今日线索动态】滚动栏，实时显示最新提交的线索，自动标注「重复诉求」「聚合线索」「高风险」标签
右侧（40% 宽度）：【案发地点分布热力图】，以辖区地图为底图，颜色越深代表欠薪线索集中度越高，点击对应区域可一键筛选该区域的全部线索，实现区域化精准管控。
3、高风险线索预警看板（通栏）
标题【高风险涉稳线索预警】，以表格形式呈现，列项包括：线索编号、涉事企业 / 包工头、涉及人数、欠薪总金额、风险等级、预警原因（如 30 人以上集体欠薪、多次重复投诉、涉稳风险），右侧操作按钮为【优先办理】【一键督办】

二、线索全生命周期管理模块
检察官点击左侧导航栏【线索管理】进入。覆盖线索归集、智能聚合、分流指派、重复诉求处理、全流程跟踪全功能，解决人工识别同一工地 / 包工头的效率难题
1、顶部筛选与操作栏（通栏）
从左到右依次为：线索状态筛选（全部 / 待研判 / 已分流 / 待审查 / 已办结 / 不予受理）、风险等级筛选、案发区域筛选、提交时间筛选、关键词搜索框（支持工地 / 企业 / 包工头 / 诉求关键词检索）、【高级筛选】按钮、【线索智能聚合】核心按钮。
2、左侧创新线索分类导航树
采用多维度分类体系，替代传统单一列表，实现线索快速定位。分类维度包括：
按线索来源：前端自主填报、12345 热线归集、人社 / 住建 / 信访等部门共享、其他单位移送
按诉求类型：支持起诉申请、欠薪投诉举报、法律咨询、其他
按聚合维度：同工地线索、同企业线索、同包工头线索、5 人以上集体投诉线索
按处理状态：待办、办理中、已办结、不予受理
3、右侧核心线索列表与详情区
列表表头固定为：线索编号、提交人信息、涉事主体、涉事项目 / 工地、欠薪金额 / 涉及人数、提交时间、线索状态、风险等级、操作按钮
每条线索默认折叠，点击左侧箭头可展开完整详情，展开后显示 4 个核心区块：
·申请人基本信息、联系方式，敏感信息默认脱敏，仅承办检察官可查看完整内容
·诉求原文展示，旁设【一键润色】按钮，点击可将农民工口语化诉求一键转化为规范法律用语（示例：用户输入「包工头欠我钱一直拖，咋办」，润色后变为「包工头拖欠本人劳动报酬，经多次催告仍拒不支付，请求检察机关依法支持起诉，维护本人合法劳动权益」），润色内容可一键同步至案件材料与法律文书
·证据材料清单，包括劳动合同、工资流水、考勤记录、欠条、音视频光盘等，每条证据旁设【查看详情】【语义识别】按钮
·AI 预分析结果，包括是否符合支持起诉基本条件、是否重复提交、是否属于聚合线索、风险等级建议
4、线索智能聚合功能（解决同一工地地址表述不一的核心难题）
点击顶部【线索智能聚合】按钮，弹出聚合设置面板，可自定义选择聚合维度（按工地 / 项目、涉事企业、包工头、案发区域）、地址匹配颗粒度、语义相似度阈值，点击【开始聚合】后，系统自动生成线索合集
技术方法阐释：
① 地址标准化预处理：对接国家地名地址数据库，将农民工填写的非标准化地址（如「XX 区东边的 XX 工地」「XX 大道旁 XX 项目」）拆解为「省 - 市 - 区 - 街道 - 路名 - 项目名」五级标准化结构，剔除模糊修饰词，提取核心地址要素
② 多维度语义相似度匹配：采用微调后的 DeepSeek 中文大模型，对项目名、施工总包单位、开发商、包工头姓名等关键词进行语义计算，匹配度≥85% 的自动判定为同一项目 / 工地，例如「XX 花园一期工地」与「XX 花园 1 标段项目部」自动识别为同一主体
③ 求并集信息整合：对判定为同一工地的线索，自动合并涉事主体、欠薪总金额、涉及人数、证据材料等信息，形成统一线索合集，同时保留单条线索的独立信息，避免遗漏关键细节
④ 人工校准兜底机制：AI 聚合结果支持检察官手动合并、拆分、调整，确保聚合准确性
页面呈现：聚合后的线索在列表中标注蓝色「聚合线索」角标，点击角标可展开合集内所有单条线索，支持批量查看、批量处理
5、同一当事人重复提交诉求识别与处理
重复诉求线索标注黄色「重复诉求」角标，鼠标 hover 可显示该当事人历史提交的所有线索、提交时间、处理状态；详情页顶部醒目提示「该当事人已于 XX 时间提交相同诉求，当前处理状态为 XX」
功能逻辑：系统通过「身份证号 + 手机号 + 姓名」匹配，同时通过语义分析识别同一事实的重复投诉；对重复诉求自动合并历史处理记录与证据材料，支持检察官一键标记「重复诉求，不予重复受理」，并自动向当事人推送短信告知处理结果
6、线索分流与重点线索自动推送
每条线索右侧设【一键分流】按钮，点击弹出分流面板，可指派给对应办案检察官、内设部门，或移送属地检察院、人社、住建等部门，填写分流意见后点击确认，系统自动推送至接收方，同步更新线索状态，生成分流记录归档
前后端衔接：前端用户勾选「需要支持起诉」的线索，系统自动标记为「重点线索」，标红置顶在待办列表最上方，同时触发弹窗提醒对应承办检察官，实现前后端无缝衔接。
7、线索全流程可追溯
每条线索详情页设【处理流程时间轴】，完整记录从线索提交、AI 预分析、检察官研判、分流、审查、受理、办结、归档的全节点，每个节点标注操作人、操作时间、处理意见，全程留痕、永久可追溯，符合检察卷宗归档要求
三、AI 辅助审查与办案模块
点击左侧导航栏【AI 辅助办案】进入，或在线索详情页点击【AI 辅助审查】直接进入对应案件页面
1、顶部固定信息栏
显示线索编号、申请人信息、涉事主体、涉案金额、案件状态，右侧设【重新 AI 审查】【导出审查报告】按钮。
2、左侧导航标签页
分为【基本诉求信息】【证据材料清单】【AI 审查意见】【案件初步分析报告】【履职办案指引】【审查结果确认】6 个标签，点击切换对应内容
3、AI辅助支持起诉资格审查
默认打开【AI 审查意见】标签页，分 3 个区块展示审查结果：
① 审查结论区：用红 / 黄 / 绿三色明确标注结论，例如绿色「经 AI 审查，该线索符合支持起诉受理基本条件，建议受理」，黄色「存在以下不符合项，建议补充材料后受理」，红色「不符合受理条件，建议不予受理」
② 审查依据区：逐条列明审查对应的《民事诉讼法》《保障农民工工资支付条例》等法律法规条款
③ 问题提示区：明确标注不符合项、材料补充要求、办案风险点
审查维度：系统内置支持起诉法定受理条件，自动完成全维度合规审查，包括申请人主体资格（是否属于弱势群体）、诉求明确性、基本事实与证据、管辖合规性、诉讼时效 5 个核心维度
合规兜底：所有 AI 审查意见仅作办案参考，页面底部设【确认审查意见】【驳回审查意见】按钮，最终审查决定权完全归属检察官，杜绝 AI 越权
4、案件初步分析报告自动生成
点击【案件初步分析报告】标签页，AI 自动生成结构化《支持起诉案件初步分析报告》，可一键导出 Word/PDF 格式归档入卷，报告内容包括：
① 案件基本情况：申请人与被申请人信息、诉求概述、涉案金额、涉及人数
② 案件焦点问题分析：AI 识别核心争议焦点，如事实劳动关系认定、工资支付主体、诉讼时效等
③ 法律适用分析：对应法律法规条款、本地类案裁判规则
④ 证据效力初步分析：现有证据证明力、缺失的关键证据
⑤ 办案优先级与切入角度建议
5、检察官履职提示与办案指引
点击【履职办案指引】标签页，顶部红色醒目标题【案件办理履职提示】，基于案件具体情况生成个性化、针对性指引，核心包括：
① 调查取证重点提示：针对案件缺失证据，明确提示需调取的材料，如「建议调取该项目农民工工资专户流水、施工总包与包工头的分包合同、项目全员考勤记录」
② 文书制作核心要点提示
③ 谈话询问重点问题清单
④ 涉稳风险防控提示（针对集体欠薪案件）
⑤ 跨部门对接指引：需对接的人社、住建等部门及对接要点
6、证据真实性审查与音视频语义分析
点击【证据材料清单】标签页，纵向单列排列所有证据，每条证据显示名称、类型、上传时间、AI 审查结果，右侧设【查看详情】【OCR / 语义识别】按钮，核心功能包括：
① 书面证据审查：对图片 / PDF 格式的合同、欠条、流水等材料，通过 OCR 识别提取内容，AI 自动校验关联性、完整性，标记瑕疵证据，如「该欠条无欠款人签字捺印，证明力不足」
② 音视频 / 光盘语义筛选：对用户上传的录音、视频、光盘文件，自动完成语音转文字、核心语义提取，生成《音视频证据核心内容摘要》，标记关键对话的时间节点与内容，解决检察官逐句听录的效率难题

四、法律文书智能生成与管理模块
点击左侧导航栏【文书管理】进入，完整覆盖需求要求的 AI 文书生成、支持起诉意见书分级审核流程。左侧为办案全流程文书模板库，右侧为文书编辑与审核区，顶部为案件信息与操作按钮：
1、AI 法律文书一键生成
左侧模板库按办案流程排序，覆盖检察办案全流程文书：支持起诉申请书（AI 生成参考版）、支持起诉意见书、询问笔录、证据目录、送达回证、案件审结报告等
操作逻辑：检察官选中模板，点击【AI 一键生成】，系统自动同步案件基本信息、审查意见、证据材料、诉求内容，填充至规范模板中，生成完整文书草稿；针对前端提交的线索，系统在通过初步审查后，自动生成参考版支持起诉书，标注「AI 生成・仅作办案参考」，检察官可直接编辑修改，无需手动填写基础信息
2、支持起诉意见书分级审核流程
文书编辑完成后，底部设【提交审核】按钮，点击后进入分级审核流程，页面显示可视化审核时间轴，完整呈现每个节点状态。审核流程包括：
① 承办检察官完成文书制作，填写承办意见，提交至部门负责人审核
② 部门负责人审核，填写审核意见，通过后提交至分管副检察长审批；重大疑难、涉众型案件需提交检察长审批或检委会讨论
③ 审批通过后，文书正式生效，支持加盖电子签章、打印、归档；审核不通过的，退回承办检察官修改后重新提交
留痕机制：系统自动留存文书修改痕迹、每一级审核意见与操作记录，全程可追溯，符合卷宗归档要求
3、文书全生命周期管理
文书列表页显示案件对应全部文书，标注文书状态（草稿 / 审核中 / 已生效 / 已归档），右侧配套【编辑】【查看】【下载】【打印】【电子签章】【归档】操作按钮；已生效文书可一键对接全国检察业务应用系统，完成卷宗归档，无需重复上传

五、批量办案与类案管理模块
点击左侧导航栏【批量办案】进入，解决同工地、同企业批量欠薪案件办理效率低的痛点。顶部为批量聚合筛选栏，中间为类案聚合合集列表，底部为批量操作按钮
1、类案智能聚合
系统按「工作地点重合度、涉事主体一致性、诉求类型相似度」三个维度，自动聚合类案形成合集，列表显示合集名称、涉及人数、涉案总金额、涉事工地 / 企业、线索数量，右侧设【进入批量办理】按钮；支持检察官自定义聚合颗粒度，从「省 - 市 - 区 - 街道 - 项目 - 标段」六级维度调整，满足不同办案需求
2、全流程批量操作
进入合集后，可勾选线索进行全流程批量处理，核心操作包括：批量 AI 审查、批量分流指派、批量文书生成、批量状态更新、批量导出归档，彻底解决同类型案件重复操作的效率难题
3、类案裁判规则推送
合集页面自动推送本地同类型支持起诉案例、法院生效裁判规则，为检察官统一类案办理标准提供参考

六、数据统计与分析模块
点击左侧导航栏【数据统计】进入，完整覆盖需求要求的线索收集统计、按案发地点分析功能，为源头治理提供数据支撑
页面分为 3 个标签页：
【综合统计报表】：按日 / 周 / 月 / 季 / 年统计线索提交数量、来源分布、类型分布、办结率，生成标准化统计报表，支持一键导出 Excel
【线索分析看板】：按辖区、街道、项目维度，统计欠薪线索数量、涉案金额、涉及人数，生成热力图、趋势图，识别欠薪高发区域、高发项目
【办案质效分析】：统计检察官人均办案量、平均办结时长、支持起诉法院采纳率等指标，为办案绩效考核提供数据支撑

七、系统设置与数据安全保障模块
仅系统管理员可访问，核心解决需求要求的「通过数据安全保障打消当事人顾虑」，同时符合检察系统数据安全规范
1、全链路国密加密与权限管控
当事人提交的个人信息、证据材料全程采用国密 SM4 算法加密存储与传输，仅案件承办检察官可查看对应案件信息，无权限人员无法访问；所有数据访问操作全程留痕、可追溯；当事人可设置敏感证据查看密码，仅本人与承办检察官可查看
2、物理隔离架构
系统采用「前端互联网端 + 后端检察内网端」物理隔离架构，前端收集的数据通过单向光闸加密摆渡至检察内网，后端办案系统完全部署于检察内网，与互联网彻底隔离，杜绝黑客攻击与数据泄露风险
3、合规脱敏与告知机制
严格遵循《个人信息保护法》，对身份证号、手机号等敏感信息在非必要场景自动脱敏；前端提交线索时，醒目告知当事人数据收集范围、使用用途、安全保障措施与个人权利，获得明确同意后再收集数据，让当事人清晰知晓信息流向，从根源上打消顾虑
4、数据留存与销毁机制
案件办结后，数据按检察卷宗管理规定加密归档，留存期限届满后，当事人可申请永久销毁个人数据，系统彻底删除且不可恢复，保障当事人的「被遗忘权」
